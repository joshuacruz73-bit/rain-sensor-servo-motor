# Karinderya ni Andreng

Isang 2D pixel-art na narrative adventure game na may story, choice-based gameplay, leaderboard, at secret achievement.

## Features
- Menu screen na may title sa kanan ng screen
- Sign-in form para sa pangalan at LRN
- Local storage database para i-save ang player profile at leaderboard
- Taglish na narration at story decisions
- Day-by-day progression na may 5-minute timer per day
- Good/bad ending based on player choices
- Points and achievements system
- Top 10 longest playing players and highest point achievers
- Key conversion system at secret cutscene: "Pass the History"

## How to run
1. Open `index.html` in a browser.
2. Click `Sign-in` and create your student profile.
3. Click `Play` to start the story.
4. Choose the best decisions to unlock the better ending and secret cutscene.

## Notes
- This is a browser-based game, so no external dependencies are required.
- The game uses the browser's local storage to save player records and leaderboards.
